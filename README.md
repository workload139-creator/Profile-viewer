# Profile-viewer
GitHub Profile Viewer

A Python-based GitHub Profile Viewer that uses the GitHub API to fetch and display public profile information such as username, name, bio, followers, following, public repositories, and profile URL.

Features

- Search GitHub users by username
- Fetch public profile information
- Display followers and following
- Show public repository count
- Simple and beginner-friendly Python project
- Uses GitHub REST API

Technologies

- Python
- Requests
- GitHub REST API

Purpose: Created for learning Python, APIs, and working with JSON data.
